# Larkdown 0.1.0

Larkdown is a native macOS editor and previewer for local Markdown files.

- Edit ordinary UTF-8 Markdown files with native save, autosave, undo, redo,
  find and replace, and full screen.
- Open Markdown files from Finder in Larkdown. If another app opens them,
  select a Markdown file, choose **File > Get Info**, choose Larkdown under
  **Open with**, and click **Change All**.
- Preview GitHub Flavored Markdown, including tables, task lists, footnotes,
  autolinks, emoji characters, highlighted code, and simple HTML such as centered logos.
- Show local and remote images in the preview. macOS may ask once for access to
  your Desktop, Documents, or Downloads folder to load local images.
- Keep UTF-8 byte-order marks and the document's line-ending style when saving.
- Check for signed updates automatically after you allow it, or choose
  **Check for Updates…** in the **Larkdown** menu.

Requires macOS 13 or later. The DMG contains a universal app for Apple silicon
and Intel Macs. Drag Larkdown to **Applications** to install it.

This first release does not include PDF export, custom themes, an outline,
Mermaid diagrams or math, bidirectional scroll synchronization, or a Mac App
Store edition. Source-to-preview scroll synchronization is supported.
